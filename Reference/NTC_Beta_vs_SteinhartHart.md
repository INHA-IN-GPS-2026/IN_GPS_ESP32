# NTC 온도 변환: Beta 방정식 vs Steinhart-Hart 방정식 오차 분석

작성일: 2026-07-07
대상: `main/sensor/sensor.c` `raw_to_temp_x100()` (10kΩ NTC, B25/50=3950, 풀다운 10kΩ 분압)
기준 진리값: 제조사 R-T 표 (10kΩ @25℃, B25/50=3950 — [Adafruit 103_3950 lookup table](https://cdn-shop.adafruit.com/datasheets/103_3950_lookuptable.pdf), MF52 계열 공통 표)

---

## 1. 현재 펌웨어 — Beta 방정식

```
1/T = 1/T₀ + (1/β)·ln(R/R₀)
```

- T₀ = 298.15 K (25℃), R₀ = 10 kΩ, β = 3950 K
- 코드: `temp_k = 1/(1/THERMISTOR_T0 + logf(r_ntc/THERMISTOR_R0)/THERMISTOR_BETA)`

β는 25℃/50℃ **2점**으로 정의된 상수라서, ln R 대 1/T 곡선을 "직선"으로 근사한다.
실제 NTC의 ln R–1/T 관계는 약한 3차 곡률이 있어, 정의점(25·50℃)에서 멀어질수록
오차가 단조 증가한다 (특히 저온).

## 2. 제안 — Steinhart-Hart 방정식 (3-point)

```
1/T = A + B·ln(R) + C·(ln R)³
```

데이터시트 R-T 표에서 3점 (T₁,R₁), (T₂,R₂), (T₃,R₃)을 골라 3×3 선형계를 풀면
A, B, C가 나온다 (Lᵢ = ln Rᵢ, Yᵢ = 1/Tᵢ[K]):

```
| 1  L₁  L₁³ |   | A |   | Y₁ |
| 1  L₂  L₂³ | · | B | = | Y₂ |
| 1  L₃  L₃³ |   | C |   | Y₃ |
```

### 산출 계수 (이 데이터시트 표 기준)

| 선정 3점 | A | B | C |
|---|---|---|---|
| **−20 / 25 / 80 ℃** (전 구간용, 권장) | 1.2689431566e−03 | 2.0878991849e−04 | 2.0740256488e−07 |
| 0 / 25 / 50 ℃ (중간 대역 최적) | 1.2829260657e−03 | 2.0785322763e−04 | 2.0054789466e−07 |
| 5 / 25 / 45 ℃ (경보대역 최적) | 1.2848502793e−03 | 2.0765447353e−04 | 2.0042807041e−07 |

3점은 **사용 범위의 양 끝 + 중앙**을 잡는 것이 원칙. 현 시스템 유효범위가
mqtt `_valid_temp` 기준 −20~80℃이므로 −20/25/80이 기본 권장.

## 3. 오차 비교 (진리값 = 데이터시트 표, 1℃ 간격 전수 평가)

### 요약 (모델 오차 |ΔT|)

| 구간 | Beta 3950 (현재) | S-H −20/25/80 | S-H 0/25/50 |
|---|---|---|---|
| 전 구간 −20~80℃ 최대 | **3.067 ℃** (@−20℃) | **0.294 ℃** (@58℃) | 0.601 ℃ (@80℃) |
| 전 구간 평균 | 0.648 ℃ | 0.153 ℃ | 0.129 ℃ |
| 전 구간 RMS | 1.039 ℃ | 0.179 ℃ | 0.209 ℃ |
| 0~60℃ 최대 | 1.074 ℃ (@0℃) | 0.294 ℃ | **0.092 ℃** |
| 35~45℃(경보대역) 최대 | 0.124 ℃ | 0.231 ℃ | **0.024 ℃** |

### 개선율

- **전 구간 최대오차: 3.067 → 0.294 ℃ = 90.4 % 감소** (S-H −20/25/80)
- **전 구간 평균오차: 0.648 → 0.153 ℃ = 76.4 % 감소** (동일)
- 0~60℃ 최대오차: 1.074 → 0.092 ℃ = 91.4 % 감소 (S-H 0/25/50)
- 경보대역 35~45℃ 최대오차: 0.124 → 0.024 ℃ = 80.6 % 감소 (S-H 0/25/50)

| **40** | **−0.119** | **+0.182** | **+0.024** |

읽는 법: Beta는 정의점(25·50℃) 근처에선 이미 ±0.13℃ 이내로 좋고, 저온으로 갈수록
급격히 나빠진다(−20℃에서 +3.1℃). S-H는 앵커 3점에서 오차 0, 그 사이에서 잔차가
최대가 되는 전형적 보간 패턴.

## 4. 펌웨어 적용

`raw_to_temp_x100()`에서 Beta 식 한 줄만 교체. 연산 추가는 곱셈 몇 회뿐
(logf는 이미 사용 중, `L³ = L·L·L`):

```c
#define SH_A 1.2689431566e-03f
#define SH_B 2.0878991849e-04f
#define SH_C 2.0740256488e-07f

float L = logf(r_ntc);
float temp_k = 1.0f / (SH_A + SH_B * L + SH_C * L * L * L);
```

ULP가 아닌 main 코어에서 1초 1회 실행되는 경로라 성능 영향 없음.

## 5. 한계 및 주의

1. **이 개선은 "R→T 모델 오차"만 줄인다.** raw→R 단계의 계통오차 —
   고정 Vref 3300 mV 가정(실제 1000~1200 mV 편차, adc_cali 미적용),
   12 dB 감쇠 비선형, 분압저항·NTC 개체 허용오차(R25 ±1 %, β ±1 %) — 는 그대로다.
   개체 허용오차만으로 25℃ 부근 ±0.2~0.3℃, ADC 경로는 그 이상일 수 있으므로,
   **Reference 온도계 대비 추종 실험은 여전히 필요**하다.
2. 위 계수는 이 데이터시트 표로 산출한 값. 실제 사용하는 NTC 부품의 데이터시트
   표(또는 실측 3점)로 재산출하면 그대로 대입 가능. 실측 3점(빙수 0℃·실온·온수
   ~50℃)으로 뽑으면 모델 오차와 개체 오차를 동시에 흡수해 가장 정확하다.
3. 경보 임계(40℃) 정확도만 최우선이면 0/25/50 계수가 유리 (경보대역 최대 0.024℃).
   전 범위(−20~80℃) 보고 정확도가 목표면 −20/25/80 계수 권장.

## 6. 재현

계산 스크립트: 데이터시트 표 −20~80℃ 101점 전수 평가, 3×3 Cramer 해법 +
numpy `linalg.solve` 이중 검증(계수 일치 확인). Beta/S-H 모두 동일 진리값 대비 평가.

## 7. 실측 캘리브레이션 결과 (2026-07-07, result.xlsx — 25/60/85℃ 3점)

센서 8개(A~H), 앵커 25/60/85℃에서 저항 3회 실측·평균 → 센서별 S-H 계수 산출 →
중간점 35/45/55/65/75℃에서 검증. 엑셀 계산을 독립 재계산으로 전수 검증했고
**완전 일치**(변환온도 차이 0.0000℃)했다.

### 7-1. 실측이 추가로 입증한 것 (근거)

**① 실제 부품의 β는 3950이 아니다.** 실측 R(25℃)/R(85℃)로 역산한 B25/85:

| 센서 | A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|---|
| R25 (Ω) | 9936 | 9941 | 9958 | 4935 | 4935 | 5018 | 5169 | 5103 |
| B25/85 실측 | 3589 | 3641 | 3691 | 4091 | 3982 | 3990 | 4011 | 3950 |

10k 그룹(A~C)의 실제 β ≈ **3590~3690**. 펌웨어 가정 3950과의 차이 때문에
Beta 모델은 75℃에서 **−3.3~−3.9℃** 오차(아래 표). §3의 "데이터시트 대비 모델
오차"보다 개체 실물 오차가 훨씬 크다 — 실측 계수 사용의 직접 근거.

**② 개체·부품 편차는 계수로만 흡수 가능.** D~H는 R25≈5kΩ(다른 부품/구성).
펌웨어처럼 R0=10k를 가정하면 **+13~+27℃** 오차로 사용 불가. 센서별 S-H 계수는
이를 자동 흡수한다.

### 7-3. 잔차 0.5~2.6℃의 원인 — 방정식이 아니라 앵커 측정

S-H 보간의 내부 모델 오차는 <0.1℃(§3)인데 잔차가 0.5~2.6℃인 이유는
**앵커 자체의 불확도**다. 시행 3회의 저항 편차를 온도로 환산하면:

| 센서 | 25℃ 앵커 | 60℃ 앵커 | 85℃ 앵커 |
|---|---|---|---|
| A | 0.01 ℃ | **3.02 ℃** (ΔR 9.8 %) | 0.96 ℃ |
| B | 0.06 ℃ | **3.02 ℃** | 0.41 ℃ |
| C | 0.02 ℃ | **3.15 ℃** | 0.87 ℃ |
| D | 0.00 ℃ | **2.71 ℃** | 0.42 ℃ |
| E | 0.01 ℃ | **3.13 ℃** | 1.19 ℃ |
| F | 0.01 ℃ | 1.96 ℃ | **3.34 ℃** |
| G | 0.05 ℃ | 0.77 ℃ | **3.73 ℃** |
| H | 0.03 ℃ | 0.46 ℃ | 0.73 ℃ |

25℃(실온 안정)는 0.01~0.06℃로 완벽한 반면, 60/85℃는 시행 간 저항이 최대
10 %+ 벌어짐 = **열평형 미도달 상태에서 측정**. 앵커가 ±1.5℃ 흔들리면 계수가
그만큼 틀어져 검증 잔차로 그대로 나타난다. 부호가 음수인 C 계수(B·D·E·H,
물리적으로 C는 +1~3e−7이 정상)도 앵커 오염의 신호다.

가장 안정적이었던 H(60℃ 0.46 / 85℃ 0.73℃)조차 잔차가 남는 것은 검증점
온도(35~75℃)를 공칭값으로 가정한 것도 한몫 — 검증 시점의 기준 온도계 실측값을
써야 한다.

### 7-4. 재실험 권고 (이대로 하면 잔차 ~0.1–0.3℃ 기대)

1. **열평형 확인 후 기록**: 각 앵커에서 저항을 연속 로깅, 변화율이 0에 수렴한
   뒤(예: 1분간 ΔR<0.1 %) 안정 구간의 중앙값 사용. 특히 60℃ 점 재측정.
2. **공칭 온도 대신 기준 온도계 실측값**을 T 앵커로 입력 (25/60/85 "설정값"이
   아니라 측정 순간의 기준계 읽음값).
3. **산출 계수 sanity check**: C가 음수이거나 |C|>1e−6이면 앵커 데이터 오염
   의심 → 해당 점 재측정.
4. 검증점도 기준계 실측 온도와 짝지어 기록.

### 7-5. 결론 (→ §8 데이터시트 대조로 보강됨)

25/60/85 실측 3점 캘리브레이션은 **이미 지금 데이터로도 Beta 대비 10k 그룹
56~60 % 오차 감소**를 입증했고, β 실측치(≈3590~3690 ≠ 3950)와 5k 개체까지
자동 흡수한다는 점에서 센서별 S-H 채택 근거는 충분하다. 남은 0.5~2.6℃ 잔차는
수식이 아니라 60/85℃ 앵커의 열평형 문제이므로, §7-4대로 재측정하면 데이터시트
분석(§3)의 모델 한계인 ~0.1℃ 수준까지 접근 가능하다.

## 8. 실측 vs EPCOS B57541G 데이터시트 대조 (2026-07-07)

같은 시리즈 10 k 품번 **B57541G1103** (특성 8307: B25/85=3478 / 특성 7003: B25/85=3612).

(곡선과 부품이 일치하면 공칭 25/60/85℃ 근처가 나와야 함).

### 8-4. 종합

1. A~C: 데이터시트(G1103, 7003)와 정합 → 데이터시트 기반 S-H(표 3점 적합)만으로도
   사용 가능하고, 센서별 실측 계수면 더 좋다.
2. D~H: A~C와 다른 모델(사용자 확인, 5k B≈4000 계열로 일관). B57541G0502
   데이터시트로 변환하면 안 되고, **센서별 실측 S-H 계수(§7-2)를 사용**한다.
   해당 모델 데이터시트 확보 시 §8-1 방식으로 정합 검증 권장.
3. 실험 방법: 앵커 욕조는 정확했고, 검증 욕조는 +0.5~1.9℃ 편향 의심 → 재실험 시
   기준 온도계 실측값 기록이 필수.
