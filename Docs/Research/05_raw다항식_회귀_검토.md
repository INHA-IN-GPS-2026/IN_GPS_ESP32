## 1. 수식 정의

### 1-1. 제안 모델 (raw 공간)

```
T̂ = Σ c_k · (raw_avg − raw₀)^k ,  k = 0 … n  (n = 3~4)
```

- `raw_avg` = ULP 200Hz 오버샘플 평균 (현행 avg_raw, n≈189)
- `raw₀` = 중심화 상수(예: 3000). **float32 조건수 때문에 필수** — 중심화 없이
  raw³(~10¹⁰)에 계수를 곱하면 유효자리 손실.
- 계수 산출: 게이팅 플래토 m점의 (raw_avg, T_ref) 쌍 LSQ. **m ≥ n+2 권장**
  (m = n+1 정확통과는 앵커 오차를 그대로 통과시킴 — S-H 3점 정확통과와 같은 함정).
- **채널별 별도 피팅** (temp1/temp2).

### 1-2. 비교 기준 모델 (lnR 공간, 현행)

```
R_app = Rp·(4095 − raw)/raw            (ratiometric, 공급 약분)
1/T   = A + B·ln(R_app) + C·(ln R_app)³   (C=0 이면 Beta식)
```

두 모델 모두 같은 raw를 입력으로 쓰므로 **공급전압 면역성은 동일**하다.
차이는 "부품·ADC 오차가 계수 공간에서 어떤 모양으로 나타나는가"뿐이다.

## 2. 핵심 차이 — 부품 공차의 인수분해

R25 공차(F등급 ±1%, 채널차의 지배 성분, 02 §3)는 **R의 곱셈 오차** `R′ = s·R`이다.

**lnR 공간**: `ln R′ = ln s + ln R` →

```
1/T = (A + B·ln s) + B·ln R = A′ + B·ln R
```

→ **A 하나만 이동**(B·C 불변). 즉 개체 1점 소크로 A′만 재산출하면 **전 구간 정확히 소거**.
07-11 채널별 A보정(40℃ 1점)이 그 구현이다.

**raw 공간**: `raw′ = 4095·Rp/(Rp + s·R)` — s가 분모에 들어가 **곡선 전체가 비선형으로
비틀린다.** 가법 offset(c₀ 이동)으로는 한 점에서만 소거되고 프로파일이 남는다(§3 ③).
완전 소거하려면 개체마다 다점 재피팅 = 개체당 소크 여러 번 = 양산 불가.

**이것이 lnR 공간이 "물리적으로 옳은 좌표"인 이유다: 지배 공차가 파라미터 1개로
인수분해된다. raw 공간에서는 안 된다.**

## 3. 시뮬레이션 (07-12, 실측 부품 B=3636·R25=9743 + 10k 분압, 이상 ADC 가정)

| 항목 | 조건 | 3차 poly (5점 LSQ) | Beta 2점 (40/75) |
|---|---|---|---|
| ① in-band 최대잔차 (35~75℃) | 골든유닛 | **0.14℃** | 모델상 0 (실제는 곡률 0.2~0.3 예상) |
| ② 외삽 25℃ | 〃 | −2.92℃ *(요구사항 제외)* | ~0 |
| ② 외삽 80 / 85℃ | 〃 | **−0.37 / −0.99℃** ⚠ | ~0 |
| ③ R25 +1% 개체, 골든곡선 적용 | 보정 없음 | −0.13~−0.38℃ | −0.26~−0.33℃ |
| ③ 〃 + **개체 1점(55℃) 보정** | 가법 offset vs A재산출 | **잔차 +0.25℃ 프로파일 잔존** | **0.000℃ (전 구간)** |

해석:
- ①: in-band 성능은 충분. 실데이터에선 **Beta가 못 잡는 ADC 굽음(고전압 비선형)까지
  poly가 흡수**한다 — 이것이 raw 회귀의 실질 장점.
- ②: 고온 외삽 오차는 화재 감시에서 수용 불가. poly를 쓴다면 캘리브 상한을
  감시 상한 이상으로 잡거나(예: 80℃ 앵커 추가), 범위 밖 raw에 외삽 플래그.
- ③: **양산 결정타.** 개체 보정이 poly에선 안 닫히고(±0.5 예산 중 0.25를 공차
  하나가 소비), Beta에선 1점으로 완전히 닫힌다.

## 4. 판정

### 4-1. 단독 채택 — 비추천

| 관점 | poly T(raw) | Beta(→필요시 S-H) |
|---|---|---|
| 골든 특성화 소크 | 4~6점 | **2점** (3점이면 S-H) |
| 개체(양산) 보정 | 1점으론 잔차 0.25 잔존, 완소거는 다점 | **1점 A재산출로 완소거** |
| ADC 굽음 흡수 | ✔ (점 충분할 때) | Beta ✘ / S-H C항 부분흡수 |
| 대역 밖 거동 | 발산 (고온측 ⚠) | 물리식이라 완만 |
| 펌웨어 | 다항식 (log 불필요) | 현행 그대로 |

### 4-2. 채택 조건 — 하이브리드 잔차층 (권장 예비안)

베이스는 현행 유지(채널별 Beta + 개체 1점 A), 그 위에 **골든유닛 공통 잔차 다항식**을
조건부로 한 겹:

```
T̂ = Beta_ch(raw)  +  P_common(T̂_beta)      (P = 2차, 골든유닛 공통, 채널 무관)
```

- **트리거**: 2점 Beta 완성 후 중간 검증(45/55/65)에서 |잔차| > 0.5℃ 이고
  그 모양이 매끄러운 굽음(=공통 ADC 비선형)일 때만.
- 공통 성분(ADC 굽음)은 P가, 개체 성분(공차)은 여전히 A 1점이 흡수 →
  poly의 유연성과 lnR 공간의 양산성을 모두 확보.
- P의 입력을 raw가 아닌 T̂_beta로 두면 P가 좁은 구간의 작은 보정(수 ℃ 진폭)이라
  발산 위험이 작고, 캘리브 상한 밖에서는 P를 동결(상수 유지)하는 클램프를 둔다.

## 5. 현황과 다음 단계 (2026-07-12 기준)

1. 펌웨어(sensor.c): ratiometric + S-H형 변환(C=0 → **Beta 모드**),
   SH_B=2.7505670e-04(벤치 B=3636 공통), SH_A 채널별 in-circuit 1점 보정
   {8.0255658e-04, 8.0375465e-04} — 기준 40.0℃ 플래토(avg_raw 2566.6/2570.7,
   R_app 5955.3/5929.4Ω, σ0.11℃). **리플래시 필요 여부 확인**(보정은 소스에만 반영된 상태였음).
2. **75℃ 게이팅 플래토 1회** → avg_raw1/2 → 채널별 B 확정(2점 Beta 완성). 같은
   플래토에서 두 채널이 동시에 나오므로 추가 비용 없음.
3. 중간 검증(45/55/65 중 1~2점): |잔차| ≤ 0.5℃ → **Beta로 확정, 종료.**
4. 초과 시: 잔차 모양이 굽음이면 §4-2 잔차층(또는 in-circuit S-H 3점), 아니면 측정 재점검.
5. 양산 플로우(변동 없음): 골든유닛 공통 B(모델당 1회) + 라인 EOL 개체 1점 A보정
   (**보정 온도는 대역 중앙 50~55℃가 B산포 영향 최소**, 02 §3 참고).

## 6. 시뮬레이션 재현 스크립트

```python
import numpy as np
B, R25, Rp = 3636., 9743., 10000.
R   = lambda T, s=1: s * R25 * np.exp(B * (1/(T+273.15) - 1/298.15))
raw = lambda T, s=1: 4095 * Rp / (Rp + R(T, s))
Tc  = np.array([35, 45, 55, 65, 75])
c   = np.polyfit(raw(Tc) - 3000, Tc, 3)          # ① 골든 3차 LSQ (중심화)
poly= lambda rw: np.polyval(c, rw - 3000)
g   = np.linspace(35, 75, 81)
print('in-band max |e|:', np.max(np.abs(poly(raw(g)) - g)))
print('외삽 25/80/85:', [round(poly(raw(t)) - t, 2) for t in (25, 80, 85)])
e   = poly(raw(g, 1.01)) - g                      # ③ R25 +1% 개체
print('개체 1점(55℃) 가법보정 후:', e - (poly(raw(55, 1.01)) - 55))
```
