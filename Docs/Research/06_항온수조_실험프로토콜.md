# 06. 항온수조 실험 프로토콜 — in-circuit 3점 캘리브 + 검증

작성일: 2026-07-12
목적: 요구사항(**25~85℃ 전구간 ±0.5℃, 경보 임계 ambient ~75℃**)을 만족하는
채널별 in-circuit S-H 3점 캘리브레이션과 그 검증을 **수조 세션 1회**로 끝내는 절차.
연계: `03_추종검증_5단계_실험설계_및_목표잔차.md`(게이팅 기준), `04`(e2e 원리),
`05_raw다항식_회귀_검토.md`(모델 선택 근거)

> 요약: **펌웨어 monitor로 캡처할 플래토 = 40 / 50 / 60 / 75 / 85 ℃ (오름차순).**
> 이 중 **40·60·85 = 캘리브 앵커**, **50·75 = 검증점**(피팅에 사용 금지).
> 75 잔차가 곧 제품(경보) 판정이다.

---

## 1. 왜 이 5점인가

| 플래토 | 역할 | 근거 |
|---|---|---|
| 40 ℃ | 앵커① + 현행 A보정 적용 확인 | 07-11 1점 보정 지점. 시작 sanity check |
| 50 ℃ | 검증점 | 앵커 사이 보간 잔차 확인 |
| 60 ℃ | 앵커② | 대역 중앙 |
| 75 ℃ | **검증점 = 경보 임계** | 여기 \|잔차\| ≤ 0.5 가 합격 조건의 본체 |
| 85 ℃ | 앵커③ | 요구대역 상단 + **ADC 최악구간(V≈2.93 V)을 앵커가 직접 통과** — 외삽 금지 원칙 |

- 3점(40/60/85)으로 채널별 S-H(A·B·C)를 풀면 부품곡률+ADC굽음+공차가 앵커에서 정확히 흡수된다(e2e).
- 25~40 하단은 선형 구간이라 완만한 외삽 — 화재예방상 우선순위 낮음(05 §결정), 추후 30℃ 1점으로 확인.

## 2. 공통 규칙 (모든 플래토 동일)

1. **수집 = 시리얼 monitor 로그** (`idf.py monitor`, avg_raw1/avg_raw2가 캘리브 데이터).
   서버/DB 경로 사용 금지 — mqtt `_valid_temp` 상한 80℃라 85℃ 데이터가 폐기됨.
   (⚠ 별건: 이 상한은 경보 75℃와 충돌. 120~150℃로 상향 필요 — 캘리브와 무관한 안전 수정)
2. **배치**: 써미스터 2개 + 레퍼런스(0.1℃급)를 **밀착·동일 깊이**, 교반 유지.
   수조 균일도 ±1.0℃(WB-6 병목)이므로 "같은 지점" 원칙이 절대적.
3. **게이팅(캡처 자격)**: PV 설정 ±0.1℃ 유지 **그리고** 레퍼런스 변화 < 0.05℃/분,
   이 상태 5분 이상 → 그 후 **1~2분 캡처**(60~120샘플; σ0.11℃ 기준 평균 불확도 무시 수준).
4. **캡처 순간의 레퍼런스 실측값 기록** (PV 아님 — PV·수조표시·써미스터 셋 다 진리 아님, 03 참고).
5. **순서 = 낮→높 고정** (가열 전용 수조: 위에서 냉각 접근 시 오버슛 꼬리가 플래토 오염).
6. 플래토마다 기록: 시각 / PV / 레퍼런스 실측 / 로그파일명 / 장착·교반 메모.

## 3. 세션 1 — 캘리브 + 검증 (예상 2~3 h)

```
40℃ ──▶ 50℃ ──▶ 60℃ ──▶ 75℃ ──▶ 85℃      (각: 승온→게이팅 5분+→캡처 1~2분)
[앵커①]   [검증]    [앵커②]   [검증=경보]  [앵커③]
```

- 40℃ 통과기준(시작 전 확인): |T1,T2 − ref| ≤ 0.3℃, 채널차 ≤ 0.2℃.
  미달이면 A보정 빌드가 안 올라간 것 → 리플래시 후 진행.
- 85℃ 주의: 승온 느려짐 + 오버슛 → 게이팅 엄수. 증발 보충수는 캡처 전에만.

**세션 후 처리(오프라인, 리플래시 불필요):**
1. 로그에서 플래토별 avg_raw1/2 평균 추출 → R_app = 10000·(4095−raw)/raw
2. 40/60/85의 (R_app, T_ref)로 **채널별 S-H 3×3** 풀이 → A·B·C
3. 50/75 avg_raw에 새 계수 적용 → 잔차 판정: **|잔차| ≤ 0.5℃(특히 75) → 합격**
4. 합격 시 sensor.c SH_A/B/C 갱신(채널별) → 플래시 → 임의 1점 최종 확인
5. 불합격 시: 잔차 모양이 매끄러운 굽음 → 05 §4-2 잔차층 검토 / 불규칙 → 해당 플래토 재측정

## 4. 세션 2 (선택, ~30분) — 채널 스왑

써미스터 1↔2 배선 교체 → 40℃ 플래토 1회.
- 채널차가 **부품을 따라가면** = 공차(개체별 보정으로 해결, 현행 구조 유지)
- **채널에 남으면** = ADC/딥/보드 (공통 원인 → 부품 교체로는 해결 안 됨)
- 양산 EOL 보정 설계의 직접 근거.

## 5. 세션 3 (선택, ~20분) — 재현성

재부팅 + 탈착·재장착 후 40℃ 재확인.
- 목적: EOL 1점 A보정의 유효수명(장착·전원 변화 내성) 확인 = 양산 신뢰성 근거.
- 통과: 세션 1의 40℃ 대비 변화 ≤ 0.2℃.

## 6. 이후 로드맵 (수조 밖)

- 30℃(또는 ambient+5 최저) 1점: 25~40 외삽 확인 — 우선순위 낮음.
- 양산 EOL: 골든 공통 계수 + 개체 1점 A보정 @55℃ 부근(양끝 B산포 균형 ±0.27℃).
- mqtt `_valid_temp` 상한 상향(80 → 120~150) 및 서버/앱 표시 범위 점검.
